# 🛵 플랫폼 배달 운전자를 위한 위험 예측 및 사고 예방 (2024)
### 🏆 중앙대학교 인문콘텐츠 연구소 연구 우수상
 
 `#데이터분석`  `#ML/AI` 

 
## 👩‍💻**주요 역할**
- 데이터 분석을 위한 기획
- 데이터 전처리 및 가공
- 데이터 시각화
- 데이터 모델링
- 생성형 AI를 통한 예측 안내 메세지 연결


## 📋 프로젝트 개요
플랫폼 노동시장 규모 확장으로 플랫폼 노동자 산재 신청 건수가 압도적으로 증가하고 있다는 문제점에 기인하여,  교통사고분석시스템 데이터의  머신러닝 분류 알고리즘을 활용한 예측 모델과 생성형 AI API로 사고 발생 예방과 산재 지원 서비스를 기획하였습니다!

1. 이륜차 사고 시 운전자의 상해 정도를 예측하는 머신러닝 모델 개발
2. 예측 모델과 생성형 AI를 연동한 실시간 위험 경고 시스템 구축
3. 사고 발생 후 산재 처리 과정을 자동으로 안내하는 시스템 개발

이를 위해 2021년부터 2023년까지의 서울특별시 이륜차 교통사고 데이터 14,944건을 분석하고, XGBoost 알고리즘을 활용하여 높은 정확도의 예측 모델을 구현했습니다.

## 🎯 결론
교통사고 분석 시스템 데이터를 활용하여 이륜차 피해 운전자의 상해 정도를 예측하는 머신러닝 모델을 개발하고, 이를 실시간 경고 시스템 및 산재 처리 지원 시스템과 연계하였습니다! 

실시간 사고 위험 예측 및 경고를 통해 안전 운전 유도, 자동화된 산재 보험 처리 과정으로 행정적 부담 감소 및 접근성 개선시키며 수집된 데이터 분석을 통한 사고 원인 파악 및 예방 대책 수립하는 데 도움이 되도록 하였습니다. 플랫폼 기업의 사고 해결 시스템 구축에 기여할 것을 기대하는 바입니다!
